# Charging the Gap: EV Adoption vs. Public Charging Infrastructure in Ontario

BSMM.8730 Data Acquisition and Management – Group Project (Fall 2026), University of Windsor
Instructor: Dr. Andreas S. Maniatis

**Team**

- Temitope Lawal – Data Analyst and BI Developer

## Problem statement
Municipal planners and charging network operators in Ontario need to know which regions have EV registrations growing faster than public charging capacity, in order to decide where to place new chargers and allocate infrastructure funding.
